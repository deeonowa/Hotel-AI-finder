# Location Pack: Большой Сочи

| Файл | Что внутри | Источник |
|---|---|---|
| `location.json` | 7 районов, хабы прибытия, сезонность цен, праздники, климат по месяцам | ручная разметка + **Open-Meteo** (климат 2019–2025) |
| `hotels.json` | 1378 отелей с признаками | **OpenStreetMap** + вычисленные признаки + DEMO-синтетика |
| `pois.json` | 1637 POI: пляжи, парки, аквапарки, площадки, станции подъёмников, достопримечательности | **OpenStreetMap** |
| `transfers.json` | время и расстояние по дорогам «хаб → отель» для всех отелей | **OSRM** (данные OSM) |

## Что реальное, что синтетическое

**Реальное (у каждого отеля):** название, тип, координаты, адрес (58%), звёзды (7% — остальные
синтетика), часть удобств; расстояние до моря — по береговой линии OSM; **подъём от ближайшего
пляжа** (`climb_to_hotel_m`, высоты Open-Meteo/Copernicus DEM) → флаг «дорога к морю в гору» и время
пешком с поправкой на подъём; **расстояния до ближайших** пляжа, аквапарка, парка, детской площадки,
станции подъёмника, достопримечательности (`nearest_m`); **трансфер по реальным дорогам**
(в агенте ×1.35 на пробки побережья, ×1.1 в горах, +8 мин подача).

**Синтетическое (DEMO, детерминированно по seed):** цены и наличие, типы номеров, питание, условия
отмены, рейтинги, правила для животных, ранний заезд, звёзды там, где нет тега. Список — в
`provenance.synthetic_fields` у каждого отеля; в интерфейсе — пометка «демо».

Отфильтрованы объекты, которые путешественнику не продаются (детские лагеря, ведомственные базы),
и дубли (один объект нанесён точкой и контуром).

## Пересобрать

```bash
cd scripts
python build_climate.py --location sochi       # климат (Open-Meteo)
python build_location.py --location sochi      # OSM + высоты + POI-признаки + OSRM; ответы кэшируются
python build_location.py --location sochi --dry-run   # только статистика
python build_location.py --location sochi --refresh   # перезапросить сеть
```

Кэш сетевых ответов — `scripts/.cache/<location>/` (в git не идёт): повторная сборка идёт офлайн и
даёт тот же результат. Нужна сеть до overpass-api.de, api.open-meteo.com, router.project-osrm.org.
